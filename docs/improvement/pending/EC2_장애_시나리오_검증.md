# EC2 장애 시나리오 검증 (카오스 엔지니어링)

> **상태**: 미결정
> **작성일**: 2026-06-19
> **선행 조건**: AWS 인프라(ALB + EC2 2대) 배포 이후 검토

---

## 현황

ALB + EC2 2대 구성이 설계되어 있으나, AWS 인프라가 아직 구축되지 않았다. 장애 발생 시 동작이 문서화되어 있지 않다.

## 확인이 필요한 지점

- 인스턴스 종료 시 처리 중이던 분산 락 콜백과 트랜잭션의 상태
- WebSocket 연결 끊김 후 클라이언트 재연결 시 상태 복구 여부
- ALB의 비정상 인스턴스 감지 및 트래픽 전환 소요 시간

## 검증 방향

실제로 EC2 한 대를 강제 종료시켜 위 시나리오를 검증하고, 복구 절차와 데이터 정합성 결과를 문서화한다. 부하 테스트(K6) 중 인스턴스를 강제 종료해 실제 영향 범위를 측정한다.
